AGENTS.md

PROPÓSITO DEL PROYECTO

Este repositorio se utiliza para crear páginas web personalizadas para pequeños negocios y profesionales.

El agente debe transformar la información entregada por cada cliente en una página web funcional, profesional, responsive y fácil de mantener.

---

ARCHIVOS IMPORTANTES

Antes de modificar una página, revisar:

- "formulario-cliente.md"
- "INSTRUCCIONES-AGENTE.md"
- "Index.html"
- "Plantilla tarjeta profesional"
- imágenes y otros recursos existentes

Función de cada archivo

"formulario-cliente.md"
Contiene las preguntas y la información que debe proporcionar el cliente.

"INSTRUCCIONES-AGENTE.md"
Contiene las reglas generales del proceso de creación de páginas.

"AGENTS.md"
Contiene las instrucciones que el agente debe seguir mientras trabaja en este repositorio.

"Index.html"
Es la página web actualmente implementada.

"Plantilla tarjeta profesional"
Es una referencia visual y funcional para la creación de nuevas páginas.

---

REGLA PRINCIPAL

La información real proporcionada por el cliente tiene prioridad sobre cualquier información existente en ejemplos o plantillas.

Nunca inventar información comercial.

No inventar:

- nombres
- teléfonos
- direcciones
- precios
- horarios
- servicios
- redes sociales
- enlaces
- promociones
- certificaciones
- opiniones de clientes

Si falta información, conservar el campo vacío, eliminar la sección correspondiente o solicitar el dato necesario.

---

PROCESO PARA CREAR UNA NUEVA PÁGINA

Cuando el usuario proporcione la información de un nuevo cliente:

PASO 1 — ANALIZAR

Leer completamente la información proporcionada.

Identificar:

- nombre del negocio
- descripción
- servicios
- teléfonos
- WhatsApp
- ubicación
- redes sociales
- horarios
- colores
- imágenes
- funciones solicitadas

PASO 2 — REVISAR LA PLANTILLA

Revisar la estructura existente antes de modificarla.

Conservar las funcionalidades que sigan siendo útiles.

No eliminar elementos funcionales sin una razón.

PASO 3 — PERSONALIZAR

Adaptar la página al nuevo negocio.

Modificar:

- textos
- títulos
- descripción
- servicios
- botones
- enlaces
- colores
- imágenes
- información de contacto

PASO 4 — REVISAR

Comprobar que:

- todos los botones funcionan
- WhatsApp utiliza el número correcto
- los enlaces de redes sociales son correctos
- Google Maps apunta al lugar correcto
- los teléfonos utilizan "tel:"
- las imágenes tienen rutas correctas
- no quedan datos del cliente anterior
- no existen enlaces ficticios

PASO 5 — RESPONSIVE

La página debe funcionar correctamente en teléfonos móviles y computadores.

Priorizar una experiencia cómoda en pantallas pequeñas.

Los botones deben ser suficientemente grandes para ser utilizados mediante contacto táctil.

---

WHATSAPP

Cuando exista un número de WhatsApp, crear un enlace funcional.

El enlace debe utilizar el número proporcionado por el cliente.

No inventar números.

Si existen dos números:

- Contacto 1 → primer número
- Contacto 2 → segundo número

Si el cliente solicita ocultar visualmente los números, mostrar solamente nombres como "Contacto 1" y "Contacto 2", manteniendo los enlaces funcionales.

---

LLAMADAS

Si existe un número telefónico, utilizar:

"tel:"

para permitir que el usuario pueda llamar directamente desde su teléfono.

---

GOOGLE MAPS

Cuando el cliente proporcione un enlace de Google Maps, utilizar exactamente el enlace proporcionado.

No modificarlo ni sustituirlo por una ubicación inventada.

---

REDES SOCIALES

Crear botones solamente para las redes sociales proporcionadas.

Ejemplos:

- Instagram
- Facebook
- TikTok

No crear enlaces ficticios.

---

IMÁGENES

Utilizar primero los recursos proporcionados por el cliente.

Respetar el logotipo existente.

No reemplazar imágenes del cliente sin autorización.

Utilizar atributos "alt" descriptivos.

---

DISEÑO

El diseño debe ser:

- profesional
- limpio
- responsive
- fácil de navegar
- rápido de cargar
- cómodo en teléfonos
- coherente con la identidad visual del negocio

Utilizar los colores proporcionados por el cliente cuando existan.

Si no existen colores definidos, mantener un diseño coherente con la plantilla.

---

CÓDIGO

Mantener el código limpio y organizado.

Evitar código innecesario.

No introducir dependencias externas innecesarias.

No introducir código malicioso.

No modificar funcionalidades que no estén relacionadas con la solicitud.

---

DATOS DEL CLIENTE ANTERIOR

Cuando se utilice una página existente como plantilla para un nuevo cliente:

Revisar cuidadosamente todo el HTML.

Eliminar o reemplazar:

- nombre anterior
- teléfonos anteriores
- WhatsApp anterior
- dirección anterior
- Google Maps anterior
- redes sociales anteriores
- servicios anteriores
- imágenes anteriores
- textos anteriores

Antes de terminar, comprobar que no quede información perteneciente al cliente anterior.

---

INFORMACIÓN FALTANTE

Si una función solicitada necesita un dato que no fue proporcionado:

No inventarlo.

Informar claramente qué dato falta.

Ejemplo:

"Para configurar el botón de Google Maps falta el enlace de ubicación."

---

CAMBIOS

Realizar solamente los cambios necesarios para cumplir la solicitud.

Evitar cambios destructivos.

Antes de reemplazar una estructura importante, revisar cómo funciona actualmente.

---

RESULTADO FINAL

Una página terminada debe:

1. Representar correctamente al negocio.
2. Mostrar únicamente información proporcionada o autorizada.
3. Tener botones funcionales.
4. Funcionar en Android y iPhone.
5. Funcionar en computadores.
6. Ser responsive.
7. Mantener una apariencia profesional.
8. No contener información del cliente anterior.
9. No contener enlaces inventados.
10. Ser fácil de modificar posteriormente.

---

COMUNICACIÓN CON EL USUARIO

Cuando termines una modificación:

Explica brevemente:

- qué se modificó
- qué funciones se agregaron
- qué información falta, si existe
- qué archivos fueron modificados

No afirmar que una función fue probada si realmente no pudo comprobarse.

FORMULARIO = información del cliente.

PLANTILLA = estructura y diseño de referencia.

AGENTS.MD = reglas que debe seguir el agente.

El agente debe combinar estos elementos para producir una página web personalizada.
